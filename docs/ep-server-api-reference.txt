 1. AOI 목록 조회
================================================================================

GET /api/AOI/list?pageNumber={n}&pageSize={size}

Parameters:
  pageNumber  int  (default: 1)
  pageSize    int  (default: 100)

Response:
{
  "items": [
    {
      "name": "인도네시아_리아우_부아탄_팜트리",
      "description": "NST-오형직 요청",
      "latitude": 0.7216,
      "longitude": 101.747,
      "altitude": 8,
      "dueDate": "2026-09-01T00:00:00",
      "englishName": "IDN_Riau_Buatan_PalmTree"
    }
  ],
  "totalCount": 14,
  "pageNumber": 1,
  "pageSize": 3,
  "totalPages": 5
}

Python 예시:
  import requests
  r = requests.get("http://192.168.0.82:8080/api/AOI/list",
                    params={"pageNumber": 1, "pageSize": 1000})
  aois = r.json()["items"]

 5. Mission 목록 조회 (selected)
================================================================================

GET /api/Mission/selected?SatelliteId={sat}&Type={type}&StartTime={start}&EndTime={end}

Parameters:
  SatelliteId  string  필수  "O1A" | "O1B" | "E3T"
  Type         string  필수  "MT" (촬영미션) | "GS" (지상국통신)
  StartTime    string  선택  ISO8601 (예: 2026-01-01T00:00:00Z)
  EndTime      string  선택  ISO8601

Response (예시, O1A MT):
[
  {
    "id": 6,
    "satelliteId": "O1A",
    "scheduleType": 1,
    "scheduleId": "O1A_13419_GGD",
    "operationId": "GGD",
    "scheduleMissionStatus": "None",
    "satelliteImageStatus": "None",
    "eventStart": "2026-04-10T03:01:54.375",
    "eventStartKST": "2026-04-10T12:01:54.375",
    "eventEnd": "2026-04-10T03:01:57.25",
    "eventEndKST": "2026-04-10T12:01:57.25",
    "location": "GGD",
    "duration": 2.875,
    "maxEl": 0,
    "latitude": 37.4299,
    "longitude": 125.2288,
    "cloudAmount": -1,
    "requestedScanTime": 9.2,
    "note": null,
    "results": null
  }
]

Python 예시:
  r = requests.get("http://192.168.0.82:8080/api/Mission/selected",
                    params={"SatelliteId": "O1A", "Type": "MT",
                            "StartTime": "2026-01-01T00:00:00Z",
                            "EndTime": "2026-12-31T23:59:59Z"})
  missions = r.json()

================================================================================
 10. TLE 조회
================================================================================

GET /api/TLE/status/{satelliteId}

Response:
  currentTle 필드: "0 HEADER\r\n1 ...\r\n2 ..." (3줄 포맷)

Python 예시:
  r = requests.get("http://192.168.0.82:8080/api/TLE/status/O1A")
  tle_str = r.json().get("currentTle", "")
  lines = tle_str.strip().split("\r\n")
  tle1, tle2 = lines[1], lines[2]
